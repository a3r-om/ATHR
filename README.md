# حروف وألوان

متجر ملفات تعليمية جاهزة للطباعة: تلوين وقصص وأنشطة للأطفال، وأوراق عمل لطلاب الابتدائي، ومواد وعروض تقديمية للمعلمات.

مبني على نفس نظام متجر **أثر** (صفحة لكل ملف وقسم، السلة، إتمام الطلب، الهدية، نقاط الولاء، أكواد الخصم، التقييمات، المفضلة، العربي والإنجليزي، عملات الخليج، ولوحة التحكم الكاملة)، مع تعديلات للملفات الرقمية:

- طريقة استلام «digital»: لا عنوان ولا شحن، والملفات تصل للزبون على واتساب بعد تأكيد الدفع.
- القالب «حروف وألوان»: الألوان البيج الأصلية للمتجر وخط Amiri.

## الملفات
- `js/` و `css/`: المتجر ولوحة التحكم.
- `tools/build.mjs`: يبني صفحات المتجر من قاعدة البيانات (يعمل تلقائياً في GitHub كل ساعة وبعد كل تعديل).
- `tools/amiri-scale.py`: يكبّر مقاسات الخط لقالب Amiri بعد أي تعديل في `css/store.css`.
- `supabase/setup.sql`: إعداد قاعدة البيانات، و `supabase/seed.sql`: الأقسام والملفات الأولى.

## لوحة التحكم
افتح رابط المتجر وأضف في آخره `#admin`.
